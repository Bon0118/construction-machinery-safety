# 第 4 阶段：视频告警

## 1. 目标

在网页中查看检测任务产生的风险告警和相关证据，并按需要推送到第三方平台。

## 2. 页面功能

- 显示视频告警列表
- 按时间和视频通道筛选
- 查看告警详情
- 预览标注图、原图和局部图
- 播放报警短视频
- 手动推送或重新推送告警
- 显示推送结果

## 3. 列表字段

- 告警时间
- 视频通道
- 机械类型
- 标注图缩略图
- 风险数量
- 推送状态
- 操作按钮

## 4. 告警详情

- 标注图 `alarm.jpg`
- 原图 `original.jpg`
- 风险局部图 `risk_crop.jpg`
- 报警短视频 `alarm_clip.mp4`
- 事件信息 `metadata.json`
- 第三方推送结果

只显示实际存在的文件；文件缺失时显示明确提示。

## 6. 推送规则

- 沿用现有 `push_alarm.py` 请求格式。
- CameraID 从视频通道配置读取。
- 图片转 Base64 后发送。
- 完整 Base64 不写入日志。
- 推送失败不能停止视频检测任务。
- 推送成功判定：`[HTTP 2xx / 第三方业务码：请填写]`。

## 7. 验收标准

- [ ] 能按时间和通道查询告警。
- [ ] 能查看告警实际存在的图片、视频和事件信息。
- [ ] 文件缺失时页面不报服务器错误。
- [ ] 手动推送成功并显示响应摘要。
- [ ] 推送失败不会影响检测任务。
- [ ] 失败告警能按确认规则重新推送。
- [ ] 自动推送、处理状态和删除功能按确认项工作。
- [ ] Base64 图片和敏感信息不出现在日志中。

## 8. 本阶段不做

- 不实现复杂工单流程。
- 不实现告警统计大屏。
- 不实现多级审核流程。
