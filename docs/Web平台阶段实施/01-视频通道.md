# 第 1 阶段：视频通道

## 1. 目标

在网页中管理摄像头或视频流，为后续检测任务提供视频源。

## 2. 页面功能

- 显示视频通道列表
- 新增视频通道
- 编辑视频通道
- 删除视频通道
- 启用或停用通道
- 测试视频连接
- 抓取一帧图片进行预览

## 3. 通道字段

| 字段 | 说明 |
|---|---|
| 通道名称 | 网页显示名称，不能重复 |
| 视频源类型 | cameraIndexCode 或直接 RTSP |
| cameraIndexCode | 通过现有接口解析 RTSP |
| RTSP 地址 | 直接视频流地址 |
| CameraID | 用于后续告警推送 |
| 启用状态 | 开启或关闭 |

## 4. 请确认

| 问题 | 你的答案                                                              |
|---|-------------------------------------------------------------------|
| 是否自动导入现有 3 个 cameraIndexCode | [是]                                                               |
| 是否保留“抓拍预览”功能 | [是]                                                               |
| 连接测试超时时间 | [60 秒]                                                            |
| 删除通道是否二次确认 | [是]                                                               |
| 是否需要支持本地视频文件 | [是]                                                               |
| 其他要求 | [cameraIndexCode取流方式和传统的纯rtsp是两种取流方式，cameraIndexCode取流需要包含断线重连功能] |

## 5. 验收标准

- [x] 能新增并保存 cameraIndexCode 通道。
- [x] 能新增并保存直接 RTSP 通道。
- [x] 连接测试能够返回成功或明确错误。
- [x] 抓拍成功时能够在网页显示图片。
- [x] 编辑后数据保持一致。
- [x] 删除操作符合确认规则。
- [x] RTSP 密码不在列表和日志中明文显示。
