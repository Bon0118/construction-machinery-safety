# Web 平台四模块实施总览

## 1. 当前范围

本机 Web 平台只实现以下四个模块：

1. 视频通道
2. 视频任务
3. 实时预览
4. 视频告警

不实现登录、数据大屏、系统信息、算法参数配置、网络配置、模型管理和运维工具。

## 2. 业务流程

```text
添加视频通道
    ↓
创建并启动视频任务
    ↓
查看实时检测画面
    ↓
查看和处理视频告警
```

## 3. 默认技术方案

- 后端：FastAPI + Uvicorn
- 页面：Jinja2 + 原生 HTML/CSS/JavaScript
- 数据：SQLite
- 实时预览：MJPEG
- 检测算法：复用现有 `MachineryHazardDetector`
- Python：`C:\Users\LENOVO\anaconda3\envs\yolov5\python.exe`
- 默认地址：`http://127.0.0.1:8000`
- 页面风格：参考智能终端管理后台，使用左侧四项菜单

需要修改的默认方案：`[无 / 请填写]`
