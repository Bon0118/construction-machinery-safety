# 第 2 阶段：视频任务

## 1. 目标

将视频通道绑定为检测任务，并通过网页启动、停止和查看运行状态。

## 2. 页面功能

- 显示视频任务列表
- 创建和编辑任务
- 启动任务
- 停止任务
- 重启任务
- 显示任务状态和最近错误

## 3. 任务字段

| 字段 | 说明 |
|---|---|
| 任务名称 | 网页显示名称，不能重复 |
| 视频通道 | 选择第 1 阶段创建的通道 |
| 自动启动 | Web 服务启动后是否自动启动任务 |
| 启用状态 | 是否允许任务运行 |

算法参数暂时直接使用现有 `config.py`，本模块不提供参数编辑页面。

## 4. 任务状态

```text
已停止 → 启动中 → 运行中
运行中 → 停止中 → 已停止
运行中 → 重连中 → 运行中/异常
```

## 6. 列表显示

- 任务名称
- 视频通道
- 当前状态
- 运行时长
- 已读取帧数
- 已推理次数
- 累计告警数量
- 重连次数
- 最近错误

## 7. 验收标准

- [ ] 可以创建任务并绑定视频通道。
- [ ] 可以启动、停止和重启任务。
- [ ] 重复点击启动不会创建重复检测线程。
- [ ] 任务状态与实际运行状态一致。
- [ ] 视频断流后按确认规则重连。
- [ ] 一路任务异常不影响其他任务和 Web 页面。
- [ ] 停止任务后释放视频连接和相关资源。
